\# Eventify



Eventify is a full-stack Event Registration System developed using Flutter, React, Node.js, Express.js, and MongoDB.



\## Features



\- View upcoming events

\- Register for events

\- Admin event management

\- View event registrations

\- Cross-platform Flutter mobile application

\- React web application



\## Tech Stack



\- Flutter (Mobile)

\- React + Vite (Web)

\- Node.js

\- Express.js

\- MongoDB



\## Project Structure



```

EventRegistrationSystem/

├── backend/

├── web/

└── flutter\_app/

```



\## How to Run



\### Backend



```bash

cd backend

npm install

npm start

```



\### Web



```bash

cd web

npm install

npm run dev

```



\### Flutter



```bash

cd flutter\_app

flutter pub get

flutter run

```
