# Eventify

## Overview

The Event Registration System is a college mini project consisting of a Flutter mobile application and a React web application connected to a common Node.js, Express.js, and MongoDB backend.

The system allows users to browse available events and register for them through both the web and mobile applications. Administrators can manage events and view registrations through the web application.

## Features

### Web Application
- Home Page
- View Available Events
- User Registration for Events
- Admin Login
- Admin Dashboard
- Add, Edit and Delete Events
- View Event Registrations


### Flutter Mobile Application
- View Available Events
- Register for Events
- Responsive Mobile Interface

## Installation

### Backend

```bash
cd backend
npm install
npm start
```

### React Web

```bash
cd web
npm install
npm run dev
```

### Flutter App

```bash
cd flutter_app
flutter pub get
flutter run
```
