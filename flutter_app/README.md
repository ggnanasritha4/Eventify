# Eventify - Flutter App

## Overview

This Flutter application is the mobile version of the **Event Registration System** developed as part of a college mini project. It allows users to browse available events and register through an easy-to-use mobile interface.

## Features

- User-friendly interface
- View available events
- Register for events
- Connects to the MERN backend using REST APIs
- Responsive mobile design

## Tech Stack

- Flutter
- Dart
- REST API
- Node.js
- Express.js
- MongoDB

## Project Structure


## Getting Started

1. Install Flutter SDK.
2. Navigate to the project directory.
3. Run:

```bash
flutter pub get
flutter run
```
